# Калькулятор доставки на Django

Практическая работа по дисциплине «Основы алгоритмизации и программирования».

Веб-приложение рассчитывает стоимость доставки по форме заявки, валидирует данные
и показывает подробный результат с возможностью применить промокод.

## Возможности

- Форма заявки: ФИО, телефон, город отправки и получения, вес, тип доставки,
  промокод, согласие с условиями.
- Расчёт: `(300 ₽ + 30 ₽ × вес) × коэффициент типа доставки`, округление до 2 знаков.
- Коэффициенты: `standard` ×1.0, `express` ×1.5, `same_day` ×2.0.
- Валидация: вес 0.1–100 кг, города не совпадают, для `express` вес ≤ 20 кг,
  обязательное согласие, проверка телефона.
- Промокоды: `SALE5` (−5%), `SALE10` (−10%), `SALE15` (−15%),
  неизвестный код — ошибка валидации (`clean_promo_code`).
- При ошибках введённые значения сохраняются, невалидные поля подсвечиваются.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Приложение откроется на <http://127.0.0.1:8000/>.

## Тесты

```bash
python manage.py test
```
